## Адаптированный проверочный лист безопасности для PropDevelopment

### Обоснование приоритетов (критические вопросы для компании):

На основе анализа кейса, следующие вопросы являются **критическими** для PropDevelopment:
- **II.7, II.8** (учет ПДн и мониторинг доступа) — из-за жалоб клиентов на утечки в ЛК
- **I.4, I.9** (минимальные привилегии и замкнутые контуры) — из-за проблем с API партнеров
- **II.9** (Data Governance) — блокирует развитие BI/ML/AI сервисов
- **IV.1-IV.3** (мониторинг и реагирование) — из-за инцидента у конкурента и нарушения процесса передачи информации ИБ
- **I.6** (журналирование) — необходимо для расследования инцидентов с утечками

### Ключевые выводы:

**Подтверждено (Да):**
- Резервное копирование выполняется для всех БД
- Доступ внешних пользователей осуществляется через firewall

**Выявлены проблемы (Нет):**
- Принцип минимальных привилегий не реализован (API партнеров видят чужие данные)
- Замкнутые контуры для чувствительных данных не созданы (внутренние потоки не контролируются)
- Учет ПДн не ведется (множественные точки регистрации без координации)
- Мониторинг доступа к ПДн отсутствует (клиенты видят чужие данные в ЛК)
- Data Governance не реализован (блокирует развитие BI/ML/AI)
- План реагирования на инциденты отсутствует (нарушен процесс передачи информации ИБ)

**Требуют проверки (Не проверено):**
- Большинство вопросов по шифрованию, аутентификации, мониторингу
- Соответствие 152-ФЗ
- Безопасность облачных ресурсов
- Физическая безопасность ЦОД
